# Editor Gráfico 2D — C++ | DirectX 11 | Dear ImGui

## Descripción

Este proyecto consiste en el desarrollo de un editor gráfico 2D interactivo creado en C++, utilizando DirectX 11 para el renderizado y Dear ImGui para la interfaz gráfica.

La aplicación permite crear, visualizar y manipular diferentes figuras geométricas sobre un lienzo basado en una cuadrícula, implementando algoritmos de rasterización y herramientas de transformación gráfica.

El editor está diseñado para explorar conceptos de computación gráfica, geometría computacional y manipulación de objetos en un entorno interactivo.

## Funcionalidades

- **Dibujo de figuras geométricas:** líneas, círculos, triángulos, cuadrados y dibujo libre.
- **Rasterización:** implementación del algoritmo de Bresenham para el trazado de líneas.
- **Dibujo de círculos:** algoritmo del punto medio para la generación de circunferencias.
- **Relleno de figuras:** opción para rellenar círculos y polígonos.
- **Selección de objetos:** selección individual de figuras mediante el mouse.
- **Transformaciones geométricas:** traslación, rotación y escalado independientes.
- **Personalización de color:** selector de color RGBA para las figuras.
- **Interacción en tiempo real:** creación y manipulación de figuras dentro del lienzo.
- **Sistema de cuadrícula:** representación gráfica basada en celdas para facilitar el dibujo y la rasterización.

## Tecnologías utilizadas

- C++
- DirectX 11
- Dear ImGui
- Win32 API
- DXGI

## Algoritmos implementados

- Algoritmo de Bresenham para líneas.
- Algoritmo del punto medio para círculos.
- Rasterización basada en cuadrícula.
- Transformaciones geométricas 2D: traslación, rotación y escalado.

## Objetivo del proyecto

Aplicar conceptos de programación en C++, fundamentos de gráficos por computador, algoritmos de rasterización y transformaciones geométricas mediante el desarrollo de una herramienta gráfica interactiva.


Proyecto desarrollado con fines académicos y de aprendizaje en programación y computación gráfica.
